Échelle typographique

Un seul jeu de rôles pour tout le site. Le H1 est le plus grand texte : rien ne le dépasse. Les mesures de cette page sont lues sur la feuille de style au moment où elle s'affiche : elles ne peuvent pas différer de ce que fait le site.

Bureau : mesure sur cet écran, largeur px. Mobile : valeurs du bloc « max-width: 859px » de la feuille de style. Les titres sont en Familjen Grotesk bold, interlettrage -.02em ; le texte est en Newsreader.

Les étiquettes (eyebrows)

Un seul style pour tous les petits repères en capitales : 14 px, police des titres, graisse 600, interlettrage .12em, interligne d'une ligne (28 px). Les classes suivantes l'emploient :

  • .eyebrow, .cartes-titre : titres de rang (« Projets personnels »).
  • .facts dt : Rôle, Client, Secteur, Date d'une étude de cas.
  • .meta, .carte .meta : repère d'une carte (nom du projet, secteur, année).
  • .legend .lt, .node .n : légendes et numéros de cellule.
  • .toc a : l'accès rapide à droite d'une étude de cas.
  • .livre-title span : auteur d'un livre.
  • .sit-num : bandeau d'une boîte de la home.

Règles

  • Le H1 de chaque page est celui du héros. Aucun texte, nombre ou citation ne dépasse sa taille.
  • Titres : police Familjen Grotesk, bold, droits (pas d'italique). Texte : Newsreader.
  • Les capitales ne servent qu'aux étiquettes (H5).
  • Pour changer une taille, on change le rôle (--t-*), pas la page.
  • Les jetons sont en tête du bloc « NOUVELLE DA » de styles.css, section « jetons » ; leurs valeurs mobiles sont dans le bloc « max-width: 859px ».
